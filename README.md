# Strength Tracker

Full-stack mobile workout tracking application built with React Native, Expo, TypeScript, and Supabase.

## Features
- User authentication
- Workout tracking
- Exercise and set logging
- Workout history
- Strength progression tracking
- Multi-screen workout workflows

## Tech Stack
- React Native
- Expo
- TypeScript
- Supabase
- PostgreSQL
- React Context

## Current Status
Currently in active development.

## Goals
The goal of this project is to build a scalable mobile application focused on strength progression, workout analytics, and intuitive workout tracking workflows.

## Future Features
- Strength progression charts
- Workout analytics
- Exercise search and filtering
- Workout templates
- Persistent active workout sessions

## Getting Started

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```
